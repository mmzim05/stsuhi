# stsuhi
sti sooee
a tui ssh manager written in go

## Install

Linux amd64, no Go toolchain needed:

```bash
curl -fsSL -o ~/.local/bin/stsuhi https://github.com/mmzim05/stsuhi/releases/latest/download/stsuhi-linux-amd64
chmod +x ~/.local/bin/stsuhi
```

Make sure `~/.local/bin` is on your `PATH`.
